# To-Do List App V2

A simple to-do list app built in python

## Features 
- Simple and Easy to use
- Clear all tasks at once
- CLI based
- List Completed Tasks

## What's New ?
- Completed Tasks are added to a seperated List.
- User can now see the list of completed tasks.
